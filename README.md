# scripts
Miscellaneous Scripts that I use

## sel_img and sel_img-qt

<https://github.com/user-attachments/assets/cdf87cdf-883d-45b9-a79c-8ce9b50d0d75>


Image selector with gallery mode and list mode. They can display images that are passed as arguments and can be used as a dmenu replacement for image files. Has asynchronous loading , optional libvips support, etc.

## pysxiv

A python implementation of sxiv. Despite being written in a slower language , it actually loads images faster than sxiv because of asynchronous loading and libvips

## themesettler
A bunch of scripts using sel_img to change themes, wallpapers, etc

## talk2

An simple terminal based AI chat program. Doesn't have much features

## ytbrowse / ytpy / ytbrowse.py

Various iterations of a terminal based youtube browser. If you prefer a more mature one, use pystardust/ytfzf instead

## select_pulse_source

A simple shell script to select output device. can also redirect the same audio to multiple output devices that you can select.
I needed this when I a wired headphone and a bluetooth one and wanted to have the same sound play on both.
